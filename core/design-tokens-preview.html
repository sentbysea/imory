Imory Design Tokens v0.1

core/design-tokens.css를 그대로 불러와 실제 토큰 값을 보여주는 페이지입니다. 이 페이지의 스타일은 전부 CSS 변수(var(--...))를 통해서만 값을 가져오므로, 토큰 파일이 바뀌면 이 페이지도 그대로 갱신됩니다. 기존 서비스 CSS는 아직 이 토큰을 참조하지 않습니다.

01 Color Primitive

실제 프로젝트 CSS에서 반복 확인된 값만 포함. 점선 태그가 붙은 항목은 아직 semantic 토큰에 연결되지 않은 primitive입니다.

02 Color Semantic — system vs theme

system-accent는 버튼의 solid fill이 아니라 system UI의 포인트 컬러로 정의합니다 — admin/admin-settings.css의 .save-button (SETTINGS 화면 저장 버튼)을 기준으로, 기본 상태는 흰 배경 + 옅은 accent-border + accent 텍스트, hover에서만 한 단계 진해집니다.
아래 두 패널은 지금 단계에서 의도적으로 거의 동일하게 보입니다. --theme-*는 나중에 사용자 스킨/AI 커스터마이징이 덮어쓸 수 있도록 네임스페이스만 분리해둔 것이고, 커스터마이징 레이어가 없는 지금은 --theme-* 기본값이 --system-*과 같은 primitive를 가리킵니다. (실제 sua 테마 CSS는 지금도 #ee9fbd 계열을 그대로 쓰고 있으며, 이 값은 primitive로 남아있지만 아직 semantic에는 연결하지 않았습니다 — 매핑표 참고)
