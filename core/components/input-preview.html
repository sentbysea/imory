Imory Core Components — Input / Textarea v0.1

core/components/input.css 설계 미리보기입니다. 아직 실제 서비스 input/textarea/select (.setting-input, .quote-text-input, .customize-field-input 등)는 .imory-field로 치환하지 않았습니다 — 이 페이지는 design-tokens.css + input.css만 불러와 독립적으로 렌더링됩니다.

00 실서비스 조사 요약

치환 전, 프로젝트 전체에서 input/textarea/select 역할을 하는 selector를 모두 비교했습니다.

그룹 selector height/padding border text focus

settings textarea .editor-block textarea 105px / 12px 14px var(--system-border) #444444 #e0bdca
quote text/textarea/select .quote-text-input 등 36~135px / 8~11px #ececec #444444~#666666 #e7b6c8

  • hover 상태는 실서비스 어디에도 없습니다 — Core Input도 hover 규칙을 두지 않기로 확정했습니다.
  • focus 색이 서로 다른 3종 outlier(#e0bdca/#e7b6c8/#e8b7c9)로 흩어져 있어 --system-accent 하나로 통일했습니다. 처음엔 design-tokens-preview.html의 focus-ring 데모(accent border + --system-shadow-focus-ring)를 그대로 승격했지만, border와 ring이 같은 색으로 겹쳐 두꺼워 보인다는 피드백으로 .imory-field:focus-visible은 box-shadow: none으로 바꾸고 1px accent border만 남겼습니다 (ring 토큰 자체는 .imory-button과 공유하므로 그대로 둠).
  • #444444가 5개 그룹 중 4개에서 반복돼 --imory-gray-750 primitive로 승격했습니다 (design-tokens-mapping.md가 이미 v0.2 후보로 예고했던 값). --system-text와는 합치지 않고 .imory-field 내부에서만 참조합니다.
  • onboarding의 bio textarea는 .imory-field--textarea 분리 없이 온보딩 화면에서 아예 제거하는 쪽으로 정리됐습니다(자기소개는 onboarding 이후 admin 설정 화면에서 입력) — 이 문서가 예고했던 치환 시나리오는 실서비스에 적용되지 않았습니다.

03 Before / After

왼쪽은 각 화면의 실제 literal 값을 그대로 재현한 것, 오른쪽은 새 .imory-field입니다. 이 페이지에서만 비교용으로 재현했고, 실제 selector는 아직 건드리지 않았습니다.

3-1. SETTINGS — .setting-input (comfortable/md)

Before — .setting-input (literal, radius 4px)
After — .imory-field.imory-field--md (radius 2px, focus 색 변경)

두 입력창 모두 클릭해서 focus 색을 비교하세요 — before는 옅은 outlier 핑크, after는 accent + ring입니다.

3-2. QUOTE — .quote-text-input (compact/sm)

Before — .quote-text-input (literal, border #ececec, radius 0)
After — .imory-field.imory-field--sm (border/radius 통일)

04 다음 단계

  • 이 preview에서 md/sm 치수, focus ring, disabled가 기대한 대로 보이는지 확인.
  • 확인되면 실제 selector 치환 순서 제안: .setting-input(settings+onboarding 공유) → .editor-block textarea → .customize-field-* → .quote-text-input/.quote-test-textarea/.quote-select-input/.quote-number-input.
  • onboarding bio textarea는 치환 시 .setting-input 단독이 아니라 .imory-field.imory-field--textarea.imory-field--md로 분리 적용 — 지금까지 있던 높이 눌림 문제가 이 시점에 자연스럽게 해결됨.
  • .quote-color-input(input[type=color])과 .quote-check-input(checkbox)은 이번 Input/Textarea 범위 밖 — 필요하면 별도 컴포넌트로 다룸.
